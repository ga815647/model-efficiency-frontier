# Task 3 — fresh public acquisition report (2026-09-26)

## Implemented interfaces

- `scripts/aa_public.py`: `SourceError(ValueError)` (`code`, `url`), `parse_leaderboard(html) -> list[dict]`, `parse_release(html, url) -> dict`, `corroborate_version(records, releases) -> dict`. Next.js script strings decoded with JSON, objects with `JSONDecoder(parse_float=Decimal).raw_decode`; duplicate slugs are checked, scores/costs compared exactly as decimals. Release versions must be explicit and agree; both designated effort pairs must match.
- `scripts/meta_pricing.py`: `parse_meta_pricing(html) -> dict`, `rescale_contributor(components, prices) -> Decimal`. Prices are matched to tier-labelled sections and column-labelled tables; current model availability, rate limits and training note required. Input = nonCacheInput + cacheWrite (cache-write billed ordinary input **assumption**); cacheRead and output billed separately. No double-counting reasoning/answer. Component totals validated with max(1e-12 absolute, 1e-10 relative) tolerance for source numeric rounding.
- `scripts/refresh_snapshot.py`: `refresh_snapshot(destination, *, previous, fetch=fetch_public) -> provenance`. Fetch URL set is fixed; default HTTP timeout 30s, up to three attempts, size cap 8MB, redirect rejection. Destination must not exist; inputs/evidence/CSV written only there. Previous inventory interface: `{'slugs': [paid_public_slug, ...], 'contributor_efforts': ['xhigh', 'max']}` (also accepts saved `source_map.json` / its `inventory`). `None` is permitted only for a genuine first run; normal runner should supply its fixed-commit approved latest inventory (initial CI runner should use an approved baseline). Disappearing public slug writes `evidence/missing_candidates.json` and fails before candidates CSV; diagnostic explicitly calls for model/index page and effort/ID review rather than asserting absence.
- Return provenance includes `benchmark`, `benchmark_version`, `version_status='inferred'`, `cost_basis='api'`, `source_dates`, `caveats`, `source_locator={'kind':'acquired','path':'snapshot/candidates.csv','sha256':<exact CSV bytes SHA256>}`. Caller hands `destination/candidates.csv` and returned provenance to `calculate_snapshot`; this module does not import calculation logic. Optional `AA_API_KEY` diagnostic is isolated under `evidence/api_envelopes.json` and checks all envelope versions without joining public rows; key absent is explicitly `not_collected`. No credential recovery or archived-run write.

## Caveats / integration

Public leaderboard itself has no version declaration: inference must remain labelled and must never be relabelled from authenticated API 4.3. Contributor cache-write billed at ordinary input rate is not Meta-confirmed; B caveat required when decisive. A missing candidate report intentionally blocks publication pending three-pass human disambiguation, not an automated absence claim. CI runner must pass fixed-commit previous inventory and use a new snapshot directory; do not treat `None` as normal on later refreshes. The optional authenticated diagnostic was not live-tested without an owner-provisioned key. No known live-source parser blocker.
